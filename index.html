Task 01 · 文件权限管理

任务描述

在右侧真实 Ubuntu 实验环境中创建 notes.txt，并将文件权限设置为仅所有者可读写。

相关知识

本关需要掌握 Linux 工作目录、文件创建、权限查看与 chmod 命令的基本使用。

实验目标 让 notes.txt 位于实验工作目录中，并通过平台测试集验证其权限为 600。

操作步骤

右侧命令行已经连接到真实 Ubuntu 工作目录。依次执行下列命令，并使用“自动测试”查看结果。

# 确认当前位置
pwd

# 创建文件并设置仅所有者可读写
touch notes.txt
chmod 600 notes.txt
stat -c "%a %n" notes.txt

编程要求

  1. 在实验工作目录中创建 notes.txt。
  2. 使用 chmod 将权限设置为 600。
  3. 使用测试按钮验证实验结果。

测试说明

自动测试会真实检查文件是否存在及权限是否正确；评测失败不会清除当前环境。实验采用受限 Ubuntu 环境，并提供代码文件与命令行操作。
